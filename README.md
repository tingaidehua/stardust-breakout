# 星尘突围 STARDUST BREAKOUT

一场"许愿式编程"的实证：**只用一句话愿望，让 AI 从零写出完整可玩的 3D 游戏。**

## 愿望原文

> 做一个让人惊叹的、画面极致酷炫的 3D 太空射击网页游戏，玩家能立刻在浏览器里玩起来。

模型：**DeepSeek-V4.1-Flash-1017**（API 名 `deepseek-flash`，2026-10-17 发布，主打"许愿式编程 / Wish-Driven Programming"）
角色分工：人类许愿 + 当 Harness（真实验证：语法检查、无头浏览器实机截图、修错迭代）；模型一次交付完整项目。

- 提示词：[`wish.md`](./wish.md)
- 生成花费：约 $0.05（77K tokens 输出，一次成型，无需返工修 bug）
- 交付：单个 `index.html`（115KB），零构建、零外部素材

## 玩法

第三人称太空射击，在无尽星云中自动前飞：

- **移动**：WASD / 方向键 / 鼠标跟随 / 触屏拖拽
- **射击**：双激光自动连射；按住空格蓄力 1 秒以上松开 → 贯穿全屏冲击波
- **敌人**：追踪无人机（正弦机动撞击）、重炮艇（扇形弹幕）、分裂体（击毁分裂成 2 个）
- **Boss**：每 5 波一艘巨型战舰，多炮塔环形弹幕 + 中央弱点核心 + 顶部血条
- **道具**：护盾 / 炸弹（B 键清屏）/ 双倍火力 / 磁铁吸附
- **计分**：击杀 × 连击倍率（最高 ×8），localStorage 保存历史最高分
- **区域**：紫晶星云 → 绯红风暴 → 冰蓝尘埃，每 2 波循环切换整套配色

## 技术亮点（全在单个文件里）

- Three.js r180 + EffectComposer + UnrealBloomPass 辉光后期 + 暗角
- 3 个自定义 GLSL Shader：fbm 流动星云背景、引擎尾焰、Boss 护盾力场
- 3000+ 点星场视差滚动、200+ InstancedMesh 小行星、对象池化爆炸粒子
- Game juice 拉满：屏幕震动、击杀闪光、受击红闪、擦弹 0.3s 慢动作、加速 FOV 拉伸、飞船转弯倾斜、Boss 登场镜头警告
- Web Audio 全合成音效 + 动态 BGM（波次/Boss 自动加层），零音频文件
- 完整流程：标题屏 → 倒计时 → 战斗 → 暂停 → 慢动作死亡 → 结算屏（得分/击杀/用时/最大连击）

## 本地运行

```bash
# 任意静态服务器，浏览器打开即可
python3 -m http.server 8000
# → http://localhost:8000/index.html
```

直接双击 `index.html` 也能玩（Three.js 从 jsDelivr CDN 加载）。
